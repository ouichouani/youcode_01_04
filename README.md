# 🃏 Digital Cards — Collection Platform

A modern and immersive web platform for discovering, collecting, buying, and managing limited-edition digital cards. The website is designed with a futuristic gaming-inspired visual style and a responsive user experience.

## 📌 Project Overview

This project is a digital card collection platform where users can explore different cards representing characters, powers, artifacts, and creatures.

The platform includes:

* 🏠 Home
* 📘 Guide
* 🏪 Market
* 🧩 My Deck
* ❤️ Favorites
* 🛒 Cart

Users can browse cards, filter them by rarity, add them to their favorites or cart, and manage their personal collection.

## 🎯 Main Objectives

* Create a dynamic and immersive digital card platform.
* Present the game's universe and rules through a dedicated Guide page.
* Build a marketplace for buying and selling digital cards.
* Allow users to manage their personal card collection.
* Implement favorites and cart functionality.
* Add filtering and pagination to the marketplace.
* Store favorites and cart data between page refreshes.
* Create a responsive experience for desktop, tablet, and mobile.
* Apply a futuristic and gaming-inspired visual identity.
* Use Tailwind CSS for the interface and styling.

## 🎓 Context

This project was completed at **YouCode** as part of a front-end development brief.

The brief was based on a fictional startup offering limited-edition digital collectible cards. The goal was to design and develop an immersive platform allowing collectors to discover, purchase, and manage their cards.

The project allowed me to practice building a more interactive front-end application while working with **responsive design, UI/UX, dynamic interactions, data persistence, and Tailwind CSS**.
